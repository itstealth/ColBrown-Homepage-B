# Col. Brown Cambridge School — Homepage, Direction B (Cinematic Heritage)

Open `index.html` in any browser, or upload the whole folder to the web server.

## Structure
- `index.html` — the complete homepage (HTML, CSS and the "A Day in the Life" tab script in one file)
- `assets/images/` — all photos and the crest, taken from the school brochure

## Fonts (Google Fonts, loaded in index.html)
- DM Serif Display — headlines
- Poppins (Regular / Bold) — body copy, labels, buttons
- Great Vibes — one signature word per layout (Centenary, in the hero)

## Colours
- Brownian Green #0F2A1E · Deep Green #0B1F16
- Crest Gold #E2B93B (dark-gold text on ivory: #6A5414)
- Ivory #F7F4EC · Parchment #EFEAD9

## Identifier — The Brownian Shield
The quartered shield outline from the crest, used large off the right edge of the hero and small as a corner device on the admissions form. One per section.
